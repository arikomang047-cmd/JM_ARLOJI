# JM ARLOJI — Website

Website React/Vite untuk toko jam tangan dan kacamata JM ARLOJI.

## Menjalankan
1. Install Node.js.
2. Buka folder ini di terminal.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka alamat localhost yang diberikan Vite.

## Deploy
Jalankan `npm run build`, lalu upload folder `dist` ke layanan hosting statis seperti Vercel, Netlify, atau Cloudflare Pages.
